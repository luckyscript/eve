## 证据等级

- **源码确认**：实现路径可核对，不等同于实际 UI 操作通过。
- **自动化状态/协议测试**：执行生产模块、确定性输入；说明替代依赖，不伪称真人操作。
- **原生组件测试**：实际 AppKit / SwiftUI 组件的事件行为，仍不等同于所有第三方输入法真机测试。
- **真实窗口验证**：记录实际版本、操作、可见结果；不能用调用成功回执代替截图/状态确认。
- **真实模型验证**：固定预算，记录是否真 SSE、调用数和验收结果；不凭模型自述认定通过。

## 必须复验的链路

1. Enter 恰好发送一次；Shift+Enter 换行；Command+Enter 兼容；组合态确认优先。
2. 粘贴多行不会发送；空白及超长输入在请求模型前给出明确反馈。
3. A、B 与新会话拥有独立草稿、契约和自动进化开关；切工作区不带入旧来源状态。
4. 运行期间能编辑草稿、浏览已缓存会话；事件和结果仍回到运行来源，不串会话。
5. 失败与断连保留提交记录及恢复入口；取消显示已请求/未命中/失败/收尾状态。
6. 正文增量跨 UTF-8 和凭据片段安全处理，不展示 reasoning，不因每个字符进行 fsync。
7. 代码块可阅读与复制；消息复制/编辑填稿不自动重放写任务。
8. 只在用户跟随底部时自动滚动；切换会话定位明确。
9. 标题列表不加载全文；超过 2 MiB 的单会话不再使整个 Bridge 断开。
10. 重命名、归档和删除有明确语义与确认；不触碰会话产生的文件。
11. 坏 JSON、坏预算均可诊断；本地修复先备份，不能自动改写全局凭据。
12. 设置编辑不被刷新静默覆盖，保存与环境变量覆盖来源明确；密钥失败后可恢复。
13. 连接测试读取模型列表，不生成回答，不输出认证信息。
14. 无工作区也能进入设置和理解下一步；空状态不出现折叠灰带。
15. 原生远程页可以启停、配对、展示状态与撤销；邀请码只在刻意打开的配对面板显示。
16. 关闭/重开、设置与搜索快捷键、任务退出收尾在实际窗口中检查。

## 回归和交付规则

定向验证后提交推送，再对远端对应源码执行 Node、Swift、TUI、中继兼容回归；失败则修复、重新推送和回归。重建 `dist/Eve.app` 与 zip，核对应用内源码版本、签名和 Git SHA。构建产物及私有证据不提交。

本轮不因纯 UI 变化重跑整套高成本技能进化演示；如改变模型流、会话或发布路径，则增加对应确定性回归及有限真实请求。真实模型请求设独立上限，不无界重试。
