# eve PoC 验证记录

日期：2026-11-12，UTC+8。结果来自本次实际执行，不是计划或示例数据。

## 交付范围

- 自行实现的最小 OpenAI-compatible Agent Loop，含完整 assistant/tool 续跑协议。
- skills 元数据发现与 system 注入，按需通过 `load_skill` 加载正文。
- readline/ANSI 滚动 TUI，多轮内存会话、命令与取消入口。
- 分层 JSON/环境/CLI 配置、字段校验与密钥脱敏。
- 工作区内文件工具、路径约束、串行执行、步数/调用数/超时限制。

本版为 Node.js 原生 ESM，无第三方运行依赖；不是 Pi/DeepSeek Harness 集成版，尚未实现自动进化控制层。

九项断言全部通过：完成状态、技能发现、先加载技能再执行任务工具、技能正文注入、工具后模型续跑、源数据正确、技能独有 nonce 正确、报告结构正确、写后读回。


## 已知限制

不提供 OS 级安全沙箱、自动上下文压缩、持久会话、崩溃恢复、写入回滚、shell、自动技能生成或能力晋级。文件工具的路径检查不适用于恶意并发修改目录的多租户场景。取消中止等待和后续派发，不能保证撤销在途 I/O。详情见 README。
